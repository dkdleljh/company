# 전력 ICT 지식백과

https://dkdleljh.github.io/company/

Notion 백과와 로컬 업무파일을 검색하고 읽는 개인 문서 포털입니다. 로컬 변경을 자동으로 확인하고 Notion 원본 첨부 검증 후 웹 저장본을 갱신합니다. 변경 감지·변환·배포에 따라 반영까지 수 분 이상 걸릴 수 있습니다.

## 문서 읽기

- 상단 햄버거 메뉴에서 업무 분류와 문서 수를 확인하고 해당 목록으로 바로 이동합니다. 검색어·파일 형식 필터는 유지되며, 분류 버튼과 메뉴 선택 상태가 함께 바뀝니다.

- PDF와 이미지는 원본 바이트 그대로 표시합니다. PDF.js를 자체 호스팅하며 페이지 이동·확대·본문 찾기를 제공합니다.
- 본문 찾기는 PDF·Office 미리보기·HWP/HWPX 페이지 서식을 유지하며 검색어 위에 노란색 표시를 겹쳐 보여줍니다. 다음 결과는 일치하는 다음 페이지로 이동합니다. 이미지로만 된 본문은 검색할 수 없습니다.
- HWP/HWPX는 글꼴을 포함한 SVG 페이지로, Excel/PowerPoint는 PDF 페이지로 변환합니다. 표와 그림을 보존하는 미리보기지만 원본 프로그램과 일부 서식이 다를 수 있습니다.
- 표 계산은 저장된 값을 사용합니다. 변환 시 매크로·외부 연결 갱신·외부 네트워크를 차단합니다. Excel은 숨김 시트를 포함한 전체 시트를 표시합니다.
- 긴 Excel 시트는 읽기 좋은 페이지로 나눕니다. 내용 누락을 막기 위해 페이지 경계의 일부 행은 겹칠 수 있습니다. 원본 파일의 행과 값은 변경하지 않습니다.
- 모든 원본은 변경 없이 저장할 수 있습니다. 실행파일, 데이터베이스, 암호화·지원하지 않는 문서는 지원 여부를 안내하고 원본 저장을 제공합니다. 실행파일을 웹에서 실행하지 않습니다.
- 검색은 제목·경로·분야·본문의 여러 검색어를 AND로 적용하고 관련도순으로 정렬합니다. 한국어 띄어쓰기와 일부 업무 약어의 별칭을 처리합니다. OCR되지 않은 이미지의 내용까지 검색된다는 보장은 없습니다.

## 콘텐츠 보호

본문·원본·색인은 AES-256-GCM으로 암호화됩니다. 접속 코드에서 PBKDF2-SHA256 600,000회로 보호키를 유도합니다. 코드와 복호화키를 브라우저 저장소에 저장하지 않으며, 잠금·새로고침 후 다시 입력해야 합니다.

암호화 파일은 같은 저장소의 별도 데이터 브랜치에 두고, 배포 manifest에서 정확한 커밋을 고정합니다. 모든 파일의 암호문 및 복호화 바이트를 SHA-256으로 확인합니다. 큰 원본은 64MiB 단위로 나눕니다. 웹페이지 자체는 GitHub Pages 용량 한도 안에 유지합니다.

공유 코드 방식은 계정별 권한·회수·접속 감사가 있는 서버 인증과 다릅니다. 기존 공개 Git 이력에 있던 자료를 소급 삭제하지 않습니다. 과거 노출 처리에는 별도 이력 정리와 자격증명 검토가 필요합니다.

## 유지보수

변환에는 `rhwp`, Poppler(`pdfinfo`, `pdftotext`), LibreOffice Flatpak, PyMuPDF가 필요합니다. PyMuPDF가 설치된 Python은 `RENDER_PDF_PYTHON`으로 지정할 수 있습니다. 변환 결과와 비공개 키는 저장소 밖에 보관합니다.

1. `scripts/render_documents.py`로 로컬 원본을 서식 미리보기로 변환합니다. 원본은 수정하지 않습니다.
2. `scripts/build_secure_bundle.cjs`에 원본 색인 경로·변환 경로·출력 경로·비공개 빌드 경로를 지정합니다. 접속 코드는 stdin으로만 입력합니다. 비공개 키는 저장소 밖에서 보관합니다.
3. 암호화 객체만 데이터 브랜치에 업로드하고 `docs/secure/manifest.json`의 `asset_base`를 해당 커밋의 raw 경로에 고정합니다. 새 객체 배포가 완료된 후 UI를 배포합니다.
4. `python3 scripts/verify_public_tree.py`, `node --test tests/*.test.cjs`, 실제 브라우저의 로그인·검색·대표 문서 검증을 완료합니다.
5. 소스 main의 docs 폴더를 GitHub Pages에 배포합니다.

이전 `build_previews.py`는 평문 텍스트 미리보기용으로 보존한 과거 구현입니다. 새 배포에 사용하지 않습니다. `docs/data`, `docs/previews`, 복호화된 원본 및 키를 커밋하면 안 됩니다.

## 외부 구성 요소

- PDF.js 6.4.299 (Apache-2.0): `docs/assets/pdfjs/LICENSE`
- 시스템 한국어 고딕 글꼴 사용. 외부 폰트 서비스에 의존하지 않습니다.

## 로컬 자동 동기화

`scripts/company_sync.py --config /보호된/설정.json`은 로컬 폴더를 기준으로 Notion 원본 첨부와 암호화 웹 자료를 갱신합니다. LLM 호출 없이 systemd 사용자 타이머로 실행합니다. 접속 코드는 저장하지 않고 기존 암호화 키와 키 봉투를 재사용합니다.

- 기본 2분 간격으로 확인하고 두 번 연속 같은 내용인 파일을 처리합니다. 임시·숨김·심볼릭 링크 파일은 제외합니다.
- 추가·수정은 Notion에 업로드한 원본을 내려받아 해시를 검증한 다음 웹에 반영합니다. HWP 등 업로드 미지원 형식과 큰 파일은 무손실 ZIP/번호순 분할 ZIP으로 보존합니다.
- 내용이 같은 단일 파일 이름 변경은 기존 Notion 문서 연결을 유지합니다. 중복 파일 사이의 애매한 이동은 임의로 판단하지 않습니다.
- 로컬 삭제는 웹 목록에서 제외하고 Notion 검증메모에 삭제 상태를 표시합니다. 기존 첨부·문서 기록은 복구용으로 보존합니다. 원본 폴더 부재·대량 삭제는 자동 반영을 중단합니다.
- 기존 백과 문서는 15분 간격으로 다시 읽으며 내용이 바뀌면 웹 저장본에 반영합니다. Notion의 수정 내용을 로컬 원본 파일에 덮어쓰지는 않습니다.
- 작업 잠금·단계별 기록과 재시도로 중복 실행을 막습니다. 원격 배포 후 Pages 상태와 실제 manifest를 검증합니다. 인증 만료·업로드 실패·연결 문제는 성공으로 표시하지 않습니다.
- 운영 상태는 보호된 state 디렉터리의 `status.json`, 개별 단계는 `journal.json`, 마지막 반영본은 `ledger.json`에 기록합니다. 키/설정/원본/로그는 Git에 포함하지 않습니다.
